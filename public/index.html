Como a execução funciona

Os arquivos e projetos ficam salvos no localStorage deste navegador. Para executar Kotlin, C e Java sem hospedar um backend próprio, o CodeLab envia o código à API pública Piston. Isso exige internet e depende da disponibilidade e das políticas desse serviço.

Não envie senhas, chaves ou código confidencial. O código é transmitido a um serviço externo para compilação e execução.

Para persistência, use Exportar ZIP regularmente. Limpar os dados do navegador pode apagar seus projetos.
